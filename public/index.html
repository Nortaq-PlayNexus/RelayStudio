01 / THE COMPUTE

Open weights. Elsewhere.

Groq is our free starting candidate. OpenRouter is an explicit alternative. Free capacity is finite; no quota evasion or automatic provider switching. Remote inference is not remote builds, tests, or terminal execution.

Groq quotas ↗OpenRouter limits ↗
02 / THE DESKTOP

A lighter native future.

Tauri + system WebView2 is the proposed native shell. Windows Credential Manager for keys, scoped workspace access, permission-gated tools. This build is still a web prototype, not an installer or autonomous agent.

Tauri security boundaries ↗Evaluate existing OpenCode first ↗
03 / THE OBJECTS

A little form. Less fuss.

Original procedural 3D meshes, shaded and rendered locally with a small WebGL renderer. Drag to rotate, switch forms, or pause. Low-power mode disables rendering. Animation caps at 24 FPS, pauses off-screen, and respects reduced motion.

04 / THE BOUNDARIES

No smoke and mirrors.

Demo replies are scripted. Live speed is unbenchmarked. No files are silently edited, no shell commands run, and downloads require review. The 3D and UI still consume local resources. No AI client can use literally zero CPU or RAM.
